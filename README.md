# Gentle Cosmic Tulip Gift

A cinematic, story-driven web experience designed to feel warm, hopeful, and deeply comforting.

## What is included
- A cinematic loading sequence with rotating messages
- A blooming tulip intro and dreamy gradient atmosphere
- A friendly, cursor-following companion with encouraging dialogue
- A typewriter-style letter with a heartfelt message
- A glassmorphism memory gallery with flip animations
- An interactive tulip garden with over 100 unique encouragements
- A star-catching mini game with compliments and fireworks
- Floating gift boxes with playful hidden messages
- Easter egg surprises, sparkles, and a final infinite-hug celebration

## Files
- index.html
- style.css
- script.js
- assets/images/
- assets/music/

## Run locally
Open index.html in a browser, or serve the folder with a simple static server.

Example:
```bash
python -m http.server 8000
```

Then open http://localhost:8000/
